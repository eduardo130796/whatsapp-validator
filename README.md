# WhatsApp Validator

Sistema de validação em massa de números via WhatsApp Web.

## Features

- Upload em lote via CSV
- Validação humanizada (anti-ban)
- Controle de limite diário
- Sistema de pausa manual vs automática
- Processamento assíncrono com BullMQ

## Stack

- Node.js
- PostgreSQL
- Redis
- Docker

## Como rodar

docker-compose up
